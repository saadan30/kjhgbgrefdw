Put your website login online

Six steps to move your website and team dashboard to Vercel with a private owner login. Tick each step as you finish it.

0 of 6 done

In GitHub

1. Delete the old website files

Open your repository on github.com. Delete index.html and 404.html: open each file, click ⋯ in the top right, choose Delete file, then Commit changes.

This matters: while index.html is there, Vercel keeps showing the old website, which has no working login.

2. Add the two new files

Pick whichever way is easier for you.

Way A: download and drag

  1. Download both files:
  2. On your computer, make a new folder named exactly api and move app.js into it.
  3. On GitHub click Add file → Upload files. Drag in the api folder and vercel.json together, then click Commit changes.

Way B: copy and paste (no folders)

  1. On GitHub click Add file → Create new file. In the name box type api/app.js (typing the slash makes the folder).
  2. Click then paste into the big box on GitHub and click Commit changes.
  3. Click Add file → Create new file again, name it vercel.json, click , paste, and commit. If GitHub says the file already exists, open vercel.json instead, click the pencil to edit, replace everything, and commit.

When you’re done, the repository’s main page lists a folder called api and a file called vercel.json.

In Vercel (one time only)

3. Add the free database

Open your project on vercel.com and go to the Storage tab. Create a database, choose Upstash for Redis, pick the Free plan, and connect it to this project. This is where your leads, jobs and employee accounts are saved.

4. Add your owner login

Go to Settings → Environment Variables and add these two. Type the names exactly as shown.

NameValue
OWNER_USERNAMESaadanSHLQadir
OWNER_PASSWORDthe password you picked for the owner

Optional: add OWNER_NAME with the name the dashboard should greet you by.

Your password stays in Vercel’s settings. It’s never in the website’s code, so nobody can find it with “View Source”.

5. Redeploy

Go to Deployments, click ⋯ on the newest one, and choose Redeploy. Vercel only picks up new settings after a redeploy.

On your website

6. Log in as the owner

Open your website, tap Employee login, and enter SaadanSHLQadir and your password. Capital letters in the username don’t matter.

From the dashboard you can create employee accounts, see website requests as they come in, and hand ownership to someone else on the Team page.

If something goes wrong

“The database isn’t connected yet”

Step 3 isn’t finished. Connect Upstash for Redis to this project in the Storage tab, then redeploy (step 5).

“The owner login isn’t set up yet”

Step 4 is missing. Check that both names are spelled exactly OWNER_USERNAME and OWNER_PASSWORD, then redeploy.

The site looks the same and the login says to use the team link

The old index.html is still in GitHub. Delete it (step 1), and Vercel updates on its own.

“404: NOT_FOUND” or the site doesn’t load

Make sure app.js is inside a folder named api and vercel.json sits at the top of the repository, not inside a folder. In Vercel, Settings → Build and Deployment, the Root Directory should be empty.

Changing the owner password later

Edit OWNER_PASSWORD in Vercel’s Environment Variables, then redeploy. Every device logged in as the owner gets logged out.
